# 11　实施计划

## 阶段0：蓝图与口径（2–3周）

- 访谈计划、采购、生产、仓库、销售和U8顾问
- 确认AS-IS流程、U8版本、接口许可和二开对象
- 完成库存、供需、BOM、批量、日历口径会签
- 选择一个代表性产品族和黄金案例

退出条件：字段映射、口径矩阵、试点范围和验收案例获批。

## 阶段1：数据与PoC（4–6周）

- 建立Python工程、CI、外挂数据库和U8只读账号
- 实现物料、BOM、库存、销售、采购、生产同步
- 实现快照、质量门禁、BOM展开和基础净需求
- 输出缺料、采购/生产建议和Pegging

退出条件：黄金案例通过，结果可以逐笔解释。

## 阶段2：完整引擎与工作台（6–9周）

- 批量、日历、冻结期、例外消息和方案对比
- 审核调整、版本冻结、权限和审计
- 性能优化、监控、备份和历史归档
- 与U8原生MRP及人工计划并行运行

退出条件：连续三个计划周期达到准确性和性能标准。

## 阶段3：受控写回（4–6周）

- 接入U8官方接口/导入机制
- 实现预校验、幂等、补偿和批次监控
- 先写草稿/申请，小范围灰度
- 完成故障、回滚、恢复和运维交接

退出条件：业务签字，写回无重复，审计链完整。

## 团队建议

| 角色 | 建议投入 |
|---|---:|
| 产品/业务分析 | 1 |
| U8顾问 | 0.5–1 |
| Python后端/MRP | 2–3 |
| 前端 | 1–2 |
| 测试 | 1–2 |
| DBA/运维 | 0.5–1 |
| 主计划员及业务代表 | 按阶段参与 |

## 首批开发任务

1. 建立脱敏数据和黄金案例，禁止直接以生产库调试。
2. 输出U8对象—标准模型映射和水位策略表。
3. 实现BOM环路、低层码和有效版本选择。
4. 实现单物料时段净需求及Pegging单元测试。
5. 建立Run/Snapshot/Scenario状态模型。
6. 以真实规模样本验证内存和批量落库方式。

## 上线原则

准确性优先于速度，可解释性优先于自动化。未达到并行验收门槛前保持只读；未验证U8接口幂等前不生成正式单据。
